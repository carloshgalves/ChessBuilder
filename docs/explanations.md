# Optional evidence assistant
Disabled unless CHESSBUILDER_EXPLAIN_ENABLED=1, CHESSBUILDER_EXPLAIN_API_KEY and CHESSBUILDER_EXPLAIN_MODEL are set. Optional CHESSBUILDER_EXPLAIN_URL is a configured HTTPS JSON chat-completions endpoint; default OpenAI endpoint. CHESSBUILDER_EXPLAIN_DAILY_LIMIT defaults to ten attempts. Explicit per-request consent and a current payload digest are required. Only FEN, played UCI and selected verified evidence are sent; no identity, PGN or private book content. Provider output is restricted to existing evidence IDs and three local pedagogical templates. Invalid output, timeout, quota and disabled state use deterministic local fallback. Cache keys include provider/model/version/payload. This is not an independently validated pedagogical improvement and the feature remains off by default.
