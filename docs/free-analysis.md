# Free analysis
Open from any actual replay position. The backend reconstructs the game prefix and legal branch, preserving repetition history. Branches are session-local and can be revisited. A separate on-demand Stockfish search uses one thread, 64 MB and three MultiPV candidates at most; batch analysis and free exploration share a search lock. Only the existing evaluation cache can be written by this workspace; game records, move analyses and jobs remain unchanged. Green arrows show the best candidate; yellow shows alternatives and dashed blue a predicted reply after the best candidate, not a proven threat. Stored replay arrows use the next move's recorded best line. No new analysis is automatically started.
