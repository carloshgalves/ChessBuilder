# Board appearance

The canonical board CSS and all 84 local SVGs were imported from carloshgalves/chessCupMotorSimulation. The original stylesheet is covered by its GPL-3.0 license (see licenses/ChessCupMotorSimulation-GPL-3.0.txt). The artwork retains its individual licenses and attribution in frontend/public/piece-assets/SOURCES.json and licenses/. The React adapter preserves the same palette and artwork IDs and uses server-provided legal moves. No remote asset service is required.
