# Resumable paired benchmark
Run `python -m chessbuilder.calibrate_bots --profile universal --strength 1600 --reference-elo 1600 --games 4`. Pause other engine workloads first. Each color pair shares a seed; each game is persisted atomically with its PGN, scores and engine identity. Resume with the identical arguments plus `--resume ID`. Incomplete games count as incomplete, not losses or draws. The Adversários panel displays reports and resume commands. The fixed-node, book-disabled protocol is not equivalent to time-controlled play or human Elo. No production calibration is certified by the short real-engine smoke test.
