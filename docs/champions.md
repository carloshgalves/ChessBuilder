# Champion collections
The catalog includes 18 classical titleholders through Gukesh and four additional FIDE titleholders during the split. It does not cover the separate women's championship. Data is fetched locally from PGN Mentor player ZIPs on explicit request, not bundled or analysed automatically. The historical importer preserves source and deduplicates exact game identities; variants in source metadata can still differ. Import all from History or run `python -m chessbuilder.champions`, or name selected slugs. Repeating the command safely reimports already linked games. CLI interruption preserves committed games. Counts are associations, not verified complete career totals. Source: https://www.pgnmentor.com/files.html.
