# Local bot practice
One-thread bounded Stockfish MultiPV search and seeded weighted legal candidate selection. Profiles weight observed activity, capture/checks, pawn structure, king safety and geometric restriction. Mirror and nemesis consult at most 200 personal games; exact position support below three uses explicit universal fallback. Strength is a nominal 800–2400 parameter, not calibrated Elo. Given identical candidate lists the sampling is deterministic; time-limited engine searches need not reproduce them. Clocks are authoritative, continue while closed, and use persisted UTC timestamps. Games can be resumed and explicitly saved as bot-source PGNs. Empirical strength/style calibration against references is not yet completed.

Opt-in benchmark: `python -m chessbuilder.calibrate_bots --profile universal --strength 1600 --reference-elo 1600 --games 4`. Each run alternates colors, excludes unfinished games from WDL, records seeds, engine binary identity and style metrics. This measures a Stockfish reference parameter, not human Elo. Use even game counts and compare profiles with the same seed and reference. Book effects are disabled in this benchmark. No benchmark is run automatically.
