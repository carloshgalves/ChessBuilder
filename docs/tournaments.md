# Tournament preparation
Local registration, dates, clock, targets, round records and linked OTB PGNs. The pre-event plan uses existing competence observations, the daily coach and clock-matched bot matches. Public opponent games must already be imported to the historical library. Preparation-specific endpoints are disabled from the event start date. Online rating is not inferred from OTB results; rating changes require recorded before/after values. Post-event scores and source-game review remain available. Bye currently counts as half a point; event-specific scoring requires a future configurable rule.
