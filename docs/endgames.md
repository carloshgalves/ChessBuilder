# Endgames
Set CHESSBUILDER_SYZYGY_DIR to a local directory of compatible .rtbw/.rtbz files. No tables are downloaded automatically. The optional remote checkbox sends only the current FEN to https://tablebase.lichess.ovh/standard. WDL ±1 is treated as a draw under the 50-move rule; uncertain DTZ at nonzero clocks is not certified. Claimable draws are accepted automatically. The original teaching positions are illustrative, not independently certified theoretical results. Exact probes adjust the objective when available; otherwise Stockfish provides bounded opposition without asserting an exact verdict. Games continue until a rule-based result; losing a tablebase advantage is not automatically graded as failure. Attempts persist using the shared training store.
Recognition records a result only when an exact rules/tablebase verdict is available; ungraded guesses are not counted. Preview uses the actual selected variant. Local tables take precedence over optional remote opposition.
